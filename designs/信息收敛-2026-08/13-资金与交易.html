去掉

  • 随注「入金 ¥0.00 · 出金 ¥0.00 · 0 笔」——hero 已经写了 ¥0.00，零值随注是同一句话说三遍。有出入金时随注自动回来。
  • 计数行「买入 0 卖出 0 出入金 0 股息 17」——整行删除。计数由各段节标携带（「股息入账 17 笔 · ¥4,280.01」就是样板）。
  • 「买卖流水 0 笔 + 本年还没有买卖记录」「出入金流水 0 笔 + 本年还没有出入金」两个空段——「0 笔」和「还没有」是同一件事的两种说法，占了四行。段落只在有流水时出现。
  • 「现金余额 未设置」大字块——未设置不配大字。收成一行金色动作「校准现金余额 →」，设置后变一行随注「现金 ¥X,XXX」。
  • 每行「股息 ·」前缀——节标已写明「股息入账」，行内不逐行重复类型。
